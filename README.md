Crystal Jailbreak
Crystal is an open-source research utility leveraging vulnerabilities within the XNU kernel for educational and security auditing purposes.

Features
 Open-Source XNU Exploits: Fully transparent implementation of kernel-level primitives utilizing a robust chain of 18 distinct kernel exploits.
 Modular Architecture: Clean separation of exploit triggers, memory management, and payload delivery.
 Community-Driven: Built for security researchers and developers to audit and improve operating system resilience.
Compatibility
 Target OS: Darwin / XNU-based environments.
 Architecture: ARM64 / Apple Silicon (research and testing configurations).
